A simple traffic simulation made for CSC335 term long project(approx 8 weeks).

Made in VS code and BlueJ IDEs (BlueJ required for CSC335 submission). Written in Java, exported to .jar file via Eclipse IDE(feels wrong using so many IDEs for this one project).
Git used for local versioning. 

Uses a GUI made with default Java libraries(Awt and Swing).

Features: placing roads of variable properties and simulating cars moving along the road, including crashes and stoping infront of red lights(this way traffic congestions can be created).

All code and art were created by me without any use of generative AI. No audio is contained in the project.
